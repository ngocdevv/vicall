# Vicall

This repository currently contains the native calling bridge used by the Vicall
Expo application.

- [`modules/expo-vicall-call-manager`](./modules/expo-vicall-call-manager) —
  CallKit, PushKit, and Android Telecom integration for Expo SDK 56+.

## Install

```sh
npm install expo-vicall-call-manager
```

See the [module documentation](./modules/expo-vicall-call-manager/README.md)
for native configuration, incoming-call payloads, and the complete API.
